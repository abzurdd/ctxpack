# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within `ctxpack`, please do **not** open a public issue.

Instead, please report it privately:
- By emailing: **iabhishek113@gmail.com**
- Or by submitting a GitHub Private Security Advisory via the repository's Security tab.

Please include:
- A description of the issue.
- Steps to reproduce or a minimal proof of concept.
- The potential impact.

We take security seriously and will review and respond promptly.
